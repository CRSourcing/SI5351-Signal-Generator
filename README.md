# SI5351-Signal-Generator
A signal generator using SI5351, ESP32 and ILI9341 touch screen. Includes AM modulator and test patterns for various amateur radio modes.Audio .wav  files can be uploaded to the ESP32 file system via WiFi and then get played via the AM modulator (3 min. max duration).An experimental device, not a fail safe building description.
